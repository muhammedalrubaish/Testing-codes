# منصة صافي — سوق الإلكترونيات المتكامل

موقع إلكتروني لمنصة **صافي**: منصة رقمية وسيطة متخصصة في الأجهزة والإكسسوارات الإلكترونية، تربط سلسلة البيع كاملة في مكان واحد:

- **تاجر الجملة** ← يبيع لتاجر التجزئة
- **تاجر التجزئة** ← يبيع للعميل النهائي
- **العميل النهائي** ← يقارن الأسعار ويشتري بأفضل عرض

## الصفحات

| الصفحة | الوصف |
|---|---|
| `index.html` | الصفحة الرئيسية: التعريف بالمنصة، آلية العمل، المزايا، الباقات، وإعلان التطبيق القادم |
| `market.html` | السوق: بحث وتصفية وترتيب للمنتجات، مع تبويب أسعار التجزئة/الجملة ونافذة مقارنة الأسعار بين المتاجر والموردين |
| `join.html` | التسجيل: اختيار الدور (جملة / تجزئة / عميل) مع نموذج تسجيل يتغير حسب الدور |

## الهوية البصرية

- الثيم: **أزرق × أبيض** (ألوان معرّفة كمتغيرات CSS في `assets/css/style.css`)
- الأيقونة: `assets/img/favicon.svg` — صاعقة بيضاء داخل مربع أزرق متدرج مع مسارات دوائر إلكترونية، صالحة كأيقونة للموقع وللتطبيق مستقبلًا
- الخط: Tajawal — واجهة عربية كاملة بالاتجاه RTL

## التشغيل

الموقع ثابت (HTML/CSS/JS) بلا أي اعتماديات بناء:

```bash
# افتح index.html مباشرة، أو شغّل خادمًا محليًا:
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## ملاحظات تقنية

- البيانات في `assets/js/data.js` **تجريبية للعرض** وتُستبدل لاحقًا بواجهة برمجية (API) حقيقية.
- الموقع متجاوب بالكامل (جوال / لوحي / سطح مكتب) تمهيدًا لتحويله إلى تطبيق.
- لا توجد عمليات دفع أو حسابات فعلية في هذه النسخة — هي نموذج أولي (Prototype) لعرض الفكرة.
