# تطبيق تحصيل الديون — ربى الوكيل القانوني لتحصيل الديون

تطبيق جوال (ويب) لإدارة ملفات المديونية والتواصل مع العملاء عبر **واتساب الشخصي** بضغطة زر، مع إصدار **سند إثبات** للدفعات.

يعمل من المتصفح مباشرة، وقابل للتثبيت على الجوال كتطبيق مستقل (PWA) يعمل دون اتصال.

---

## المزايا

### 1. صفحة العملاء
- سجل كامل لكل عميل: **الاسم ورقم الجوال** (إلزاميان)، و**رقم الهوية / السجل** (اختياري)، وإجمالي المديونية، وقيمة القسط، وتاريخ الاستحقاق، وملاحظات.
- بحث فوري بالاسم أو رقم الهوية أو الجوال.
- تصفية حسب الحالة: **متأخر / مستحق / مسدّد** (تُحسب تلقائيًا من تاريخ الاستحقاق والمبلغ المتبقي).
- ملف تفصيلي لكل عميل: المتبقي في الذمة، شريط نسبة السداد، وسجل الدفعات.
- **زر علامة صح** بجانب كل عميل لتعليم الملف كمسدَّد بالكامل: يتحوّل الصف إلى **تظليل أخضر** مع شارة صح بجانب الاسم، ويخرج من قائمة المستحقات. الضغط عليه مرة أخرى يُرجع الملف إلى المديونيات القائمة (ويحذف دفعة التسوية التي أُنشئت تلقائيًا).

### 2. أزرار سريعة للتحويل إلى واتساب
كل زر يفتح محادثة واتساب مع العميل والنص جاهز داخلها:

| الزر | الاستخدام |
|---|---|
| **ترحيب بالعميل** | رسالة تعريف أولى بالوكيل وبيان المديونية |
| **تذكير بسداد الدفعة** | تذكير ودّي بالمبلغ وتاريخ الاستحقاق |
| **إشعار تأخر** | إشعار بتجاوز موعد السداد مع عدد أيام التأخير |
| **سند إثبات** | إرسال صورة سند استلام الدفعة مع نص مرافق |
| **إخلاء طرف** | إشعار بسداد كامل المديونية |

النص قابل للتعديل في نافذة المعاينة قبل الإرسال، وهناك زر نسخ للنص.

### 3. إرفاق ما يثبت السداد
عند تسجيل أي دفعة يُنشئ التطبيق **صورة سند (PNG)** محليًا على الجهاز تتضمن:
رقم السند المتسلسل، اسم العميل ورقم هويته وجواله، المبلغ المستلم، طريقة السداد، التاريخ، إجمالي المديونية والمسدَّد والمتبقي، نص الإقرار، واسم المحصّل مع مكان توقيع العميل.
عند السداد الكامل يتحول السند تلقائيًا إلى **سند إخلاء طرف**.

الإرسال يتم بأحد طريقين:
- **مشاركة السند** — تفتح قائمة مشاركة الجهاز، اختر واتساب فتُرفق الصورة والنص معًا (عبر Web Share API، مدعوم على أندرويد و iOS).
- **حفظ الصورة** — تنزّل الصورة ثم ترفقها يدويًا في المحادثة (بديل على الأجهزة التي لا تدعم المشاركة).

> واتساب لا يسمح بإرفاق ملف تلقائيًا عبر رابط `wa.me`، لذا الإرفاق يمر عبر قائمة المشاركة أو الحفظ اليدوي — وهذا هو أقصى ما تتيحه المنصة دون واتساب للأعمال.

### 4. قوالب رسائل قابلة للتعديل
خمسة قوالب جاهزة يمكن تعديل نصوصها وحفظها، مع متغيرات تُستبدل تلقائيًا:

`{الاسم}` `{الهوية}` `{الجوال}` `{الإجمالي}` `{المسدد}` `{المتبقي}` `{المبلغ}` `{العملة}` `{التاريخ}` `{تاريخ_الاستحقاق}` `{أيام_التأخير}` `{رقم_السند}` `{المحصل}` `{الصفة}` `{جوال_المحصل}`

### 5. الوضع الفاتح والداكن
الثيم **زيتي فاتح** افتراضيًا، مع زر تبديل في الترويسة وفي الإعدادات. الاختيار محفوظ ويبقى بعد إغلاق التطبيق.

### 6. قاعدة بيانات فعلية (Supabase)
بيانات العملاء والدفعات مرتبطة بقاعدة بيانات PostgreSQL حقيقية، فلا تضيع لو فُقد الجهاز، وتفتح نفس الملفات من أي جهاز.

- **الجداول:** `clients` (ملفات العملاء) و`payments` (الدفعات) و`profiles` (إعدادات المحصّل وقوالبه).
- **الأمان:** كل جدول محمي بـ Row Level Security — كل صف مرتبط بحساب صاحبه، ومستخدم آخر لا يستطيع قراءة أو تعديل صف واحد من بياناتك حتى لو عرف رابط القاعدة.
- **العمل دون اتصال:** التطبيق يكتب محليًا أولًا ويعمل كاملًا بلا إنترنت، ثم يرفع التغييرات تلقائيًا عند عودة الاتصال.
- **المزامنة:** تلقائية بعد كل تعديل (بتجميع التعديلات المتتالية)، وعند فتح التطبيق، وعند عودة الإنترنت — مع زر **«مزامنة الآن»** يدويًا.
- **التعارض:** عند تعديل الملف نفسه من جهازين تفوز النسخة الأحدث زمنيًا.
- **الحذف:** حذف ناعم (`deleted_at`) لتنتقل عمليات الحذف بين الأجهزة بدل أن يعود السجل المحذوف عند المزامنة التالية.

الربط اختياري: بدون تسجيل دخول يبقى التطبيق يعمل محليًا كما كان.

## الخصوصية

- التواصل عبر **واتساب الشخصي** المثبّت على الجهاز (رابط `wa.me`) — لا يتطلب واتساب للأعمال ولا أي API ولا رسوم.
- البيانات محفوظة في `localStorage` على الجهاز، وعند ربط الحساب تُرفع نسخة إلى قاعدة بياناتك الخاصة على Supabase وتحميها سياسات RLS.
- المفتاح العام (publishable key) الموجود في `cloud.js` مُصمَّم للنشر العلني؛ الحماية الفعلية من سياسات RLS، فلا يستطيع أحد قراءة بياناتك بمعرفة المفتاح وحده.
- سند الإثبات يُنشأ محليًا داخل المتصفح (Canvas) ولا يُرفع لأي جهة.
- في الإعدادات: **تصدير نسخة** (ملف JSON) و**استيراد** لنقل البيانات بين الأجهزة أو الاحتفاظ بنسخة احتياطية.

## التشغيل

```bash
# من مجلد المشروع
python3 -m http.server 8000
# ثم افتح: http://localhost:8000/debt-app/
```

للتثبيت على الجوال: افتح الرابط في المتصفح ← قائمة المتصفح ← **إضافة إلى الشاشة الرئيسية**.

> ملاحظة: خاصية «مشاركة السند» وعامل الخدمة (العمل دون اتصال) يتطلبان تشغيل الموقع عبر `https` أو `localhost`.

## أول استخدام

1. **الإعدادات** ← عدّل اسم المحصّل والصفة وجوال التواصل والعملة ومفتاح الدولة ← حفظ.
2. **العملاء** ← زر **+** ← أضف بيانات العميل (الاسم والجوال إلزاميان، والهوية اختيارية).
3. **الإعدادات ← قاعدة البيانات السحابية** ← سجّل الدخول لربط بياناتك بالقاعدة (اختياري لكنه موصى به).
4. من ملف العميل: أرسل الترحيب، أو التذكير، أو سجّل دفعة وأرسل سندها.

لتجربة الواجهة بسرعة: **الإعدادات ← تحميل بيانات تجريبية** (يمكن مسحها لاحقًا بزر حذف جميع البيانات).

## البنية

```
debt-app/
├── index.html               # هيكل التطبيق (4 تبويبات + شاشة ملف العميل)
├── manifest.webmanifest     # بيانات التثبيت كتطبيق
├── sw.js                    # عامل الخدمة — العمل دون اتصال
└── assets/
    ├── css/app.css          # الثيم الزيتي — متغيرات CSS للوضعين الفاتح والداكن
    ├── img/icon.svg         # أيقونة التطبيق
    └── js/
        ├── cloud.js         # الاتصال بـ Supabase: تسجيل الدخول وواجهة REST
        ├── store.js         # طبقة البيانات والقوالب والحسابات (localStorage)
        ├── sync.js          # المزامنة: رفع التغييرات وتنزيل الجديد وحل التعارض
        ├── proof.js         # مولّد صورة سند الإثبات + المشاركة
        └── app.js           # منطق الواجهة والتنقل وروابط واتساب
```

### مخطط قاعدة البيانات

| الجدول | الأعمدة الأساسية |
|---|---|
| `clients` | `id, user_id, name, national_id, phone, total, installment, due_date, notes, settled, settled_at, created_at, updated_at, deleted_at` |
| `payments` | `id, client_id, user_id, amount, paid_on, method, note, ref, auto, created_at, updated_at, deleted_at` |
| `profiles` | `id (= معرّف المستخدم), collector, role, phone, currency, country_code, templates (jsonb), seq` |

بدون أي اعتماديات بناء — HTML/CSS/JS خالص.
